# Калькулятор пряжи — Мания пряжи

Текущая тестовая версия полностью разделена на три пользовательские вкладки:

1. **Образец** — до/после ВТО, итоговая плотность, изменение размеров, рабочий метраж смеси до 5 видов пряжи и итоговый состав смеси.
2. **Изделие** — ориентировочный расход для выбранного изделия и размера. Можно использовать данные из вкладки «Образец» или вводить плотность и рабочий метраж вручную. Сложения нити из этой вкладки удалены.
3. **Подбор пряжи** — подбор из внутреннего VK-каталога по рассчитанному изделию.

## Старт приложения

При каждом запуске сначала показывается экран предупреждения об ориентировочном характере расчётов. Только после нажатия «Согласен, продолжить» приложение открывается и запускает обновление каталога VK.

## VK-каталог

Тестовая конфигурация:

- группа: `173909287`
- owner_id: `-173909287`
- альбом: `310875173`
- маркер описания: `#Калькулятор`

Приложение получает фотографии тестового альбома через VK API и передаёт во внутренний парсер только описания с маркером `#Калькулятор`. Парсер не показывается пользователю отдельной вкладкой.

## Расчёт смеси нитей

Для каждого из максимум 5 видов пряжи задаются длина, вес, число одновременно используемых нитей и состав. Метраж каждого вида нормализуется в м/100 г. Итоговый метраж смеси вычисляется через сумму массы одного метра всех составляющих. Итоговый состав взвешивается по массе одного метра каждой составляющей.

## Образец

До ВТО вводятся: петли, ряды, ширина, высота, вес. После ВТО: ширина и высота. Калькулятор выводит плотность до/после ВТО, изменение размеров и расход по площади. При заполненной рабочей нити также оценивается число метров, ушедших на образец.

## Изделие

Расход по изделию использует существующие ориентировочные базовые метражи из `js/data.js`, коэффициент плотности и запас 10%. Это ориентир, а не гарантия фактического расхода.
