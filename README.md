# Калькулятор пряжи — Мания пряжи

Приложение состоит из трёх вкладок:

1. **Калькулятор образца** — метраж и состав смеси до 5 нитей, плотность до/после ВТО и изменение размеров.
2. **Калькулятор изделия** — расчёт по российскому размеру и фактическим размерам изделия в сантиметрах.
3. **Подбор пряжи** — подбор из внутреннего VK-каталога по рассчитанному рабочему метражу.

## Образец

Обязательные данные: петли, ряды, ширина и высота до ВТО, ширина и высота после ВТО.

Вес образца **необязателен**. Если он указан, калькулятор получает фактический расход в г/100 см² и использует его как основной метод расчёта изделия (при совпадающей плотности и рабочем метраже). Если веса нет, изделие всё равно рассчитывается геометрически по площади и плотности.

## Российские размеры и геометрия изделия

Для взрослых размер связан с обхватом груди: например RU 46 → ОГ 92 см. Для женщин используется базовый рост 164 см, для мужчин — 176 см. Детская сетка строится по росту и базовому обхвату груди.

После выбора изделия и размера приложение подставляет расчётные размеры готового изделия в сантиметрах. Пользователь может исправить обхват, длину, длину рукава, ширину рукава и другие параметры под конкретную модель. Расход считается уже по этой геометрии, а не по фиксированному табличному числу метров.

Для джемпера/пуловера, свитера, жакета и жилета рассчитывается площадь корпуса и соответствующих деталей; для свитера отдельно учитывается воротник, для жакета — планки. Для шапки, шарфа, шали, одеяла, носков и рукавиц используются их собственные геометрические модели.

Добавлены отдельные изделия **«Женский свитер»**, **«Мужской свитер»** и **«Детский свитер»**.

## Метод расхода

Если есть вес образца, расход масштабируется по фактической массе площади образца после ВТО.

Если веса нет, используется геометрическая оценка для лицевой глади: по плотности петель и рядов оценивается средняя длина петли, затем длина нити на рассчитанную площадь изделия. Этот режим остаётся ориентировочным и менее точным, чем расчёт по взвешенному образцу.

К итоговому расходу добавляется запас 10%. Узоры, косы, резинки, карманы, капюшоны, планки и другие детали могут изменить реальный расход.

## Размерные стандарты, использованные как база

- ГОСТ 31409-2009 — трикотажные верхние изделия для женщин и девочек.
- ГОСТ 31410-2009 / ГОСТ Р 53147-2008 — трикотажные верхние изделия для мужчин и мальчиков.
- ГОСТ Р 52771-2007 — типовые фигуры женщин.
- ГОСТ Р 52774-2007 / ГОСТ 31399-2009 — типовые фигуры мужчин.
- ГОСТ 17916-86 — типовые фигуры девочек.
