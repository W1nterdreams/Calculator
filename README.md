# Мания пряжи — Калькулятор пряжи (VK Mini App)

Готовая статическая первая версия мини-приложения. Работает без сервера: расчёт, разбор свободных описаний пряжи, локальный тестовый каталог и подбор по рабочему метражу.

## Что уже работает

- выбор изделия с графическими иконками;
- размеры для 16 типов изделий;
- плотность 8–30 петель на 10 см;
- метраж в формате «метры / граммы»;
- 1–10 сложений;
- расчёт ориентировочного метража и веса с запасом 10%;
- проверка соответствия рабочего метража выбранной плотности;
- парсер свободного текста: страна, бренд, название, цвет, состав, метраж, номер пряжи, остаток, цена;
- три тестовых описания из реальных примеров;
- подбор из каталога: приложение перебирает 1–12 сложений и ищет наиболее близкий рабочий метраж;
- локальное добавление описаний через вкладку «Каталог / парсер»;
- вызов VKWebAppInit через официальный VK Bridge при запуске внутри VK.

## Структура

- `index.html` — интерфейс и SVG-графика изделий;
- `assets/styles.css` — адаптивный дизайн;
- `assets/icon.svg` — иконка приложения;
- `js/data.js` — изделия, размеры, базовые нормы и диапазоны метража;
- `js/parser.js` — разбор свободных текстовых описаний;
- `js/app.js` — логика интерфейса, расчёт и подбор.

## Запуск локально

Можно открыть `index.html`, но лучше через простой HTTP-сервер:

```bash
python3 -m http.server 8080
```

После этого открыть `http://localhost:8080/`.

## GitHub Pages

Загрузите содержимое папки в репозиторий и включите Pages для корня ветки. Приложение не требует сборки npm.

## VK Mini Apps

В настройках VK Mini App укажите URL опубликованной страницы. Приложение использует официальный `@vkontakte/vk-bridge` 2.14.0 через CDN и отправляет `VKWebAppInit` при наличии Bridge.

Для полностью автономной production-сборки VK Bridge позже лучше собрать локально в bundle, чтобы не зависеть от CDN.

## Важное про нормы расхода

Текущая база — рабочая **ориентировочная модель для первой версии**. Базовое значение задаётся для плотности 20 п./10 см, затем применяется табличный коэффициент плотности. Перед публикацией как окончательного расчётчика стоит отдельно утвердить/заменить таблицы расхода для каждого изделия и размера на выбранный эталонный источник.

## Следующий этап — реальные фото VK

Сейчас каталог тестовый/локальный. Для автоматического анализа реальных фотографий сообщества нужно подключить получение фото и их `text`/описаний через VK API, после чего передавать каждое описание в `ManiaParser.parseDescription(text, { photoUrl })`.

## Интеграция каталога VK — 19 альбомов

Сборка `20261001-vk19-01` умеет загружать каталог непосредственно из выбранных фотоальбомов группы `173909287` (для VK API используется `owner_id=-173909287`).

Разрешённые альбомы задаются в `js/config.js` одним массивом `ALBUM_IDS`. Сейчас в нём ровно 19 ID:

`282549589, 282549604, 282549619, 306350292, 306738634, 282549634, 282549658, 282549768, 282549711, 282549724, 282549679, 282549696, 282549748, 282549789, 282549985, 282549816, 282549829, 282549737, 282549844`.

Во вкладке «Каталог / парсер» появилась кнопка «Обновить из VK». При нажатии приложение:

1. берёт фактический `vk_app_id` из параметров запуска Mini App;
2. запрашивает разрешение `photos`;
3. получает названия альбомов группы;
4. читает фотографии только из перечисленных 19 альбомов;
5. передаёт `photo.text` в существующий `ManiaParser.parseDescription()`;
6. сохраняет распознанный каталог в IndexedDB;
7. использует этот каталог во вкладке «Подбор пряжи».

В каталоге отображаются миниатюра фотографии, название альбома и ссылка «Открыть фото VK». Для защиты интерфейса от тысяч карточек одновременно выводится по 60 позиций с кнопкой «Показать ещё». Кэш VK хранится отдельно от вручную добавленных локальных позиций.


## Тестовый режим VK: один альбом + маркер

Для отладки VK-каталога используется только альбом:

- https://vk.ru/album-173909287_310875173
- owner_id: `-173909287`
- album_id: `310875173`

В каталог калькулятора передаются только фотографии, в тексте которых присутствует маркер `#Калькулятор` (регистр не важен). Все остальные описания пропускаются до запуска `parser.js`.

Рекомендуемый формат нового описания:

```text
#Калькулятор
Страна: Италия
Бренд: Xinao
Название: Cashfeel
Артикул: 2/30
Цвет: аметист
Состав: 100% меринос
Метраж: 1500 м/100 г
Остаток: 1030 г
Цена: 340 руб/100 г

Описание:
Свободный пользовательский текст.
```

Подписанные поля разбираются приоритетно. Старый свободный формат парсера оставлен как резервный режим.
